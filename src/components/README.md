# Components

Ce dossier contient uniquement des composants d'interface purs. Un composant
reçoit ses données et ses actions par propriétés : il n'importe ni le client
HTTP, ni un service API, ni un store global.

- `ui/` : composants génériques ;
- `catalogue/` : liste, cartes, recherche et filtres ;
- `book-details/` : fiche, formulaire, notes et couvertures.
